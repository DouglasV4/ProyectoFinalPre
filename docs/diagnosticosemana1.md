# Diagnóstico Semana 1 - CHATBOTRENTADEVEHICULOS

## 1. Información General

*Proyecto:* CHATBOTRENTADEVEHICULOS  
*Módulo:* Desarrollo de Aplicaciones con IA  
*Semana:* Semana 1  
*Equipo:* RentaCar

---

## 2. Problema Identificado

Las empresas de renta de vehículos necesitan administrar información relacionada con:

- Vehículos.
- Clientes.
- Reservas.
- Alquileres.
- Disponibilidad.

Cuando estos procesos se realizan manualmente, se pueden producir:

- Errores.
- Pérdida de tiempo.
- Dificultad para consultar información.
- Falta de control sobre los vehículos.

---

## 3. Situación Actual

El sistema se encuentra en una etapa de prototipo funcional.

Actualmente se cuenta con:

- Interfaz web.
- Datos simulados.
- Inventario de vehículos.
- Registro de clientes.
- Registro de reservas.
- Asistente virtual.
- API REST.

---

## 4. Usuarios Identificados

### Dueño del negocio

Necesita supervisar:

- Vehículos disponibles.
- Vehículos alquilados.
- Reservas.
- Actividad general del negocio.

---

### Secretaria

Necesita:

- Consultar información.
- Gestionar alquileres.
- Verificar disponibilidad.

---

### Cliente

Necesita:

- Consultar vehículos disponibles.
- Conocer precios.
- Obtener información rápidamente.

---
